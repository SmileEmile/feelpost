## 2. 产品定位与设计约束（只保留与模块划分相关的部分）

**一句话定位**：从 Java 源码自动产出可信接口契约，在本机完成调试验证，再把结构化文档交给 AI 前端使用的**本地接口契约中枢**。

| 约束 | 对模块划分的含义 |
|---|---|
| 离线可用为硬底线 | 不设"云端同步/在线校验/在线更新"模块；核心能力必须本机闭环。AI 为可选扩展，见 `06.AI模块详细设计.md`；未配置 AI 时不影响离线使用 |
| 单机单用户 | 不设账号、权限、团队、共享、审计模块 |
| 仅 Java + Spring Boot 注解式 | 扫描模块的能力边界明确，不做通用语言解析 |
| 手动触发扫描 | 不设文件监听/常驻发现模块 |
| 无断言与自动回归 | 用例模块只做"请求快照 + 汇总"，不设执行引擎/断言/报告模块 |
| 接口资产 = 源码层 + 人工层 | 注册模块必须同时承载自动更新与人工不覆盖两种写入来源 |

## 4. 功能模块划分

### 4.1 模块总览

| M4 | 环境与参数 | 维护"请求上下文"：前置 URL、参数、凭据、网络选项 | 业务域 |
| M5 | 调试执行 | 用当前上下文发请求、展示响应、产出示例与 curl | 业务域 |
| M6 | 用例管理 | 沉淀可复用的请求快照并汇总 | 业务域 |

### 4.2 各模块职责与边界

#### M1 项目空间

- **职责**：创建/打开/切换项目；保存项目元信息（名称、源码目录、描述、本地环境前置 URL）；维护"当前项目"上下文。
- **输入**：用户填写的项目信息、系统目录选择结果。
- **输出**：项目上下文（供 M2 扫描、M3–M7 全部模块使用）。
- **不负责**：接口解析、环境参数细节、文档生成。
- **关键约束**：项目是数据组织的第一维度；接口、环境、用例、文档均归属项目。

#### M2 源码扫描

- **职责**：按用户选择的范围解析 Spring Boot 源码，产出接口候选与变更集；维护扫描快照；标记解析完整度。
- **输入**：项目源码目录、扫描范围、上次扫描快照。
- **输出**：扫描结果（新增/变更/删除 + 差异说明 + 解析完整度），交给 M3 的待确认队列。
- **不负责**：是否入库（由 M3 的授权决定）、接口的人工说明、请求调试。
- **关键约束**：
  - 仅 Java + Spring Boot 注解式；支持 GET/POST/PUT/PATCH/DELETE（HEAD 后置，DQ12）；
  - 手动触发，无常驻监听；
  - 增量基于快照 + 指纹，不依赖文件时间戳；
  - 解析失败不阻塞入库，转"部分解析/失败"。

#### M3 接口资产与生命周期

- **职责**：项目内接口清单的唯一事实来源；承载源码层 + 人工层合并；维护四态状态机；承载手工新建接口。
- **输入**：扫描结果（M2）、用户授权动作、人工编辑、手工新建。
- **输出**：接口资产（含生效定义与状态），供 M4 预览参数、M5 调试、M6 关联用例、M7 生成文档。
- **不负责**：解析源码、决定请求上下文、生成 md。
- **关键约束**：
  - 接口身份 = 方法 + 完整路径；
  - 人工层永不被扫描覆盖；
  - 归档接口保留、可恢复为已注册、默认不导出，恢复前不参与调试（DQ10）；
  - 手工接口不参与扫描比对。

#### M4 环境与参数

- **职责**：环境 CRUD 与切换；维护前置 URL、环境参数、凭据、证书与代理；维护全局参数；提供"生效参数"合并结果。
- **输入**：用户配置、接口定义（用于合并展示）。
- **输出**：当前环境的请求上下文（前置 URL、合并后参数、网络选项），供 M5 与 M7 使用。
- **不负责**：发送请求、保存用例、生成文档。
- **关键约束**：
  - 环境 = URL + 整套参数与凭据，切换即整套生效；
  - 环境覆盖全局，同名键环境胜出；
  - token/cookie 手工填写，无自动登录、无变量链；
  - 超时按环境配置（默认 30s，DQ13）；
  - 凭据明文存储（风险 R2）。

#### M5 调试执行

- **职责**：构造请求、发送、展示响应；产出 curl 与响应示例。
- **输入**：接口定义（M3）、请求上下文（M4）、用户填写的参数/文件。
- **输出**：调用结果（状态码/头/体/耗时/大小）、响应示例（写回 M3）、curl 文本。
- **不负责**：环境配置、用例汇总、文档导出、断言与自动回归。
- **关键约束**：
  - 请求参数合并顺序：全局 → 环境 → 接口本地；
  - 请求体支持 JSON / form / multipart；
  - 失败需区分证书、代理、超时、连接拒绝；
  - 无断言、无自动重试（DQ13）。

#### M6 用例管理

- **职责**：把用户调通的请求保存为冻结快照；提供用例汇总、筛选、查看、删除；提示受接口变更影响的用例。
- **输入**：M5 的当前请求、接口标识、环境标识、用户填写的名称/标签/备注。
- **输出**：用例资产；用例 md 导出内容（交给 M7）。
- **不负责**：执行用例、断言、自动回归。
- **关键约束**：用例保存后与接口定义解耦；接口变更只提示不改写；用例归属项目与接口。

#### M7 文档与导出

- **职责**：把接口资产（源码层+人工层）与响应示例生成基础 6 块 md；提供预览、源码视图、复制、下载；导出用例 md；可选读取 M10 的 AI 接入摘要并追加固定章节。
- **输入**：接口资产（M3）、当前环境（M4）、用例（M6）。
- **输出**：md 文本 / 本地 JSON 文档资产。
- **不负责**：解析源码、发请求、修改接口定义。
- **关键约束**：
  - 基础 6 块，不含用例、不含"鉴权要求"（Q23）；
  - 可选追加「AI 前端接入摘要」章节（M10 扩展），固定章节、同名覆盖；
  - 导出内容必须反映人工层补充；
  - 导出范围：全部 / 仅已注册与已变更 / 单接口（已确认纳入，DQ7）。

#### M8 应用外壳与导航（支撑）

- **职责**：四工作区导航、项目与环境切换、主题、扫描入口、全局反馈（toast/弹窗）。
- **输入**：当前项目/环境状态。
- **输出**：统一的界面容器与交互入口。
- **不负责**：业务规则本身；不持有业务数据。
- **关键约束**：离线可用；主题本地持久化；高频路径短。

#### M9 本地数据与偏好（支撑）

- **职责**：本地持久化与读取；凭据明文存储；主题/最近项目/最近环境偏好；数据目录可迁移性。
- **输入**：各模块的读写请求。
- **输出**：本机数据与偏好。
- **不负责**：业务规则、网络通信。
- **关键约束**：离线、无服务端、无账号；数据可整体备份（待确认 P2-2）；AI API Key 使用系统安全存储。

#### M10 AI 辅助（可选扩展）

- **职责**：在用户配置并主动触发时，调用 OpenAI-compatible 模型完成字段说明、AI 用例和前端接入摘要。
- **输入**：接口契约、已保存示例、选中用例、AI 配置。
- **输出**：可审阅的 AI 结果、AI 元信息、独立 AI 接入文档；用户确认后由 M3/M6/M7 应用。
- **不负责**：自动执行请求、修改源码、断言、项目级问答、RAG。
- **关键约束**：默认关闭；不发送源码；敏感 Header 脱敏；不保存原始 Prompt/响应；未配置时不影响核心离线功能。

## 5. 模块关系

### 5.1 关系总览

```
                     ┌──────────────────────────────┐
                     │ M8 应用外壳与导航（支撑）      │
                     │ 项目/环境切换 · 导航 · 主题    │
                     └──────────────┬───────────────┘
                                    │ 承载与调度
   ┌────────────┐   目录/项目上下文   │
   │ M1 项目空间 │──────────────────▶│
   └─────┬──────┘                    ▼
         │ 工程目录            ┌─────────────┐
         └────────────────────▶│ M2 源码扫描  │
                               └──────┬──────┘
                                      │ 扫描结果（新增/变更/删除 + 差异）
                                      ▼
                               ┌─────────────┐
                               │ M3 接口资产  │◀── 授权 / 人工编辑 / 手工新建
                               └──┬───┬───┬──┘
                   接口定义 + 状态 │   │   │ 接口定义
                     ┌────────────┘   │   └──────────────┐
                     ▼                ▼                  ▼
              ┌────────────┐   ┌────────────┐    ┌────────────┐
              │ M4 环境参数 │   │ M5 调试执行 │    │ M7 文档导出 │
              └─────┬──────┘   └──┬──────┬──┘    └──────▲─────┘
                    │ 请求上下文   │      │ 响应示例        │ 用例 md
                    └─────────────▶│      ▼               │
                                   │  ┌──────────┐        │
                                   │  │ M6 用例   │────────┘
                                   │  └──────────┘
                                   ▼
                          实际发请求（本机 → 目标服务）

              ┌──────────────────────────────────────┐
              │ M9 本地数据与偏好（支撑，横切所有模块）│
              └──────────────────────────────────────┘
```

### 5.2 依赖方向与耦合内容

| 依赖 | 方向 | 耦合内容 | 说明 |
|---|---|---|---|
| M1 → M2 | 项目上下文 | 源码目录、项目标识 | 扫描必须知道扫哪个工程 |
| M2 → M3 | 扫描结果 | 新增/变更/删除 + 差异 + 解析完整度 | M3 不直接读源码，只消费结果 |
| M3 ↔ M5 | 双向 | 读接口定义；写回响应示例 | 示例属于接口的人工层 |
| M3 ↔ M6 | 单向 + 提示 | 用例关联接口；接口变更影响用例 | 用例不反向修改接口 |
| M4 → M5 | 请求上下文 | 前置 URL、合并参数、证书/代理 | 环境切换只改变上下文 |
| M4 → M7 | 导出上下文 | 前置 URL 与 curl 中的环境 | 文档导出需要当前环境 |
| M5 → M6 | 请求快照 | 当前请求的完整参数与请求体 | 保存用例的动作发生在调试页 |
| M6 → M7 | 用例数据 | 用例清单与明细 | 用例 md 导出 |
| M8 → 全模块 | 导航与状态 | 当前项目、当前环境、当前工作区 | 外壳不持有业务数据 |
| M9 → 全模块 | 持久化 | 读写本地数据 | 支撑域，横切 |

### 5.3 边界设计要点（防止职责漂移）

1. **M2 与 M3 的边界是"候选 vs 事实"**：扫描只产出候选，必须经授权才成为接口资产；M2 不写正式清单。
2. **M3 与 M6 的边界是"定义 vs 快照"**：接口定义可变，用例快照不可被扫描改写；M6 只读接口标识，不依赖接口字段的实时值。
3. **M4 与 M5 的边界是"配置 vs 执行"**：M4 只提供上下文，不发请求；M5 不修改环境配置。
4. **M7 是纯读侧**：只消费 M3/M4/M6 的数据，不回写业务状态。
5. **M9 不含业务规则**：只做存取与偏好，不判断"是否应入库"这类规则。

## 6. 核心业务流程

### 6.1 首次接入工程

| 步骤 | 参与模块 | 说明 |
|---|---|---|
| 1 | M1 / M8 | 新建项目：名称 + 源码目录（目录选择器）+ 本地环境前置 URL |
| 2 | M2 | 选择扫描范围（默认整个工程）并扫描 |
| 3 | M2 | 解析接口，产出新增/变更/删除（首次全部为新增） |
| 4 | M3 | 待确认队列 → 用户勾选 → 授权入库 |
| 5 | M3 / M8 | 接口树出现接口（默认收起为模块列表） |
| 6 | M4 / M5 | 切到环境 → 确认生效参数 → 发送请求验证 |
| 7 | M5 / M6 | 保存响应示例、保存用例 |
| 8 | M7 | 导出 md |

**分支**：解析失败 → 标记"部分解析/失败"，仍可入库；用户取消授权 → 本次结果丢弃、下次重扫（DQ8）。

### 6.2 增量扫描与授权入库（含范围选择）

| 步骤 | 参与模块 | 说明 |
|---|---|---|
| 1 | M8 / M2 | 触发扫描，选择范围：整个工程 / 指定目录 / 指定模块（Maven 模块 → 包） |
| 2 | M2 | 解析范围内源码，与上次快照对比，产出变更集 |
| 3 | M3 | 结果页展示"新增 N / 变更 M / 删除 K"，分类勾选 |
| 4 | M3 | 确认后：新增入库、变更标记"已变更"、删除标记"已归档" |
| 5 | M3 / M6 | 对"已变更"接口，提示受影响的用例"基于旧定义" |
| 6 | M3 | 再次扫描时，已处理项不再重复出现（新增去重、归档不再提示） |

**分支**：范围内无变化 → 提示"没有发现变更"；只扫局部时，范围外的快照如何处理见 §9-DQ1。

### 6.3 调试闭环

| 步骤 | 参与模块 | 说明 |
|---|---|---|
| 1 | M3 / M5 | 选中接口，按其定义生成请求草稿（path/query/header/body/cookie） |
| 2 | M4 | 当前环境提供前置 URL、参数、凭据、证书/代理 |
| 3 | M4 | 合并参数：全局 → 环境 → 接口本地；环境覆盖全局 |
| 4 | M5 | 发送请求，展示状态码/头/体/耗时/大小；失败给出可操作提示 |
| 5 | M5 / M3 | 保存响应示例（写回接口人工层） |
| 6 | M5 / M6 | 保存用例（冻结完整请求快照） |
| 7 | M5 | 复制 curl（含当前环境与生效参数） |

### 6.4 用例沉淀与汇总

| 步骤 | 参与模块 | 说明 |
|---|---|---|
| 1 | M6 | 保存用例：名称、标签、备注、环境、冻结请求 |
| 2 | M6 | 一个接口可保存多组用例 |
| 3 | M6 | 汇总页统计与列表；按标签/关键字筛选 |
| 4 | M6 | 查看用例快照、复制 curl、删除 |
| 5 | M6 → M7 | 导出用例 md |

### 6.5 文档导出

| 步骤 | 参与模块 | 说明 |
|---|---|---|
| 1 | M7 | 选择导出范围（全部 / 仅已注册与已变更 / 单接口）与当前环境 |
| 2 | M3 | 读取接口定义（源码层 + 人工层）与响应示例 |
| 3 | M7 | 生成 6 块 md；预览或查看 Markdown 源码 |
| 4 | M7 | 复制到剪贴板 / 下载 `.md` |

### 6.6 横切：环境切换

| 步骤 | 参与模块 | 说明 |
|---|---|---|
| 1 | M8 / M4 | 顶栏切换环境 |
| 2 | M4 | 整套参数与凭据生效；证书/代理随环境 |
| 3 | M5 / M7 | 后续请求与导出使用新环境的前置 URL |
| 4 | M3 / M6 | 接口清单、用例内容不因环境切换而改变 |

### 6.7 接口状态流转

```
              授权入库
  待确认 ──────────────▶ 已注册
                          │  ▲
            扫描发现变更   │  │  用户确认变更（DQ3）
                          ▼  │
                        已变更
                          │
            扫描发现删除   │
                          ▼
                        已归档  ── 可恢复为已注册，不物理删除（DQ10）
```

## 7. 关键业务规则（设计必须遵守）

| 编号 | 规则 | 出处 |
|---|---|---|
| BR-1 | 接口身份 = HTTP 方法 + 完整路径；同路径不同方法视为不同接口 | 基线 §7.1 |
| BR-2 | 接口指纹 = 方法 + 完整路径 + 参数集合摘要；参数变化即"已变更" | 基线 §7.2 |
| BR-3 | 源码层随扫描更新；人工层只追加、不覆盖；展示与导出取合并 | 基线 §7.3 |
| BR-4 | 任何扫描产出入库前必须经用户确认 | 基线 §7.4 |
| BR-5 | 环境参数覆盖全局参数；同位置同名键由环境胜出 | 基线 §7.5 |
| BR-6 | 用例保存后与接口定义解耦；接口变更只提示、不改写 | 基线 §7.6 |
| BR-7 | 切换环境只影响请求上下文，不影响接口清单与用例 | 基线 §7.7 |
| BR-8 | 解析失败不阻塞入库，转"部分解析/失败"等待人工补全 | 基线 §7.8 |
| BR-9 | 基础导出固定 6 块，不含用例、不含鉴权要求；AI 接入摘要为可选追加章节 | 基线 FR-T2 / Q23 / AI 扩展 |
| BR-10 | 仅扫描 GET/POST/PUT/DELETE；仅 Spring Boot 注解式 | 基线 FR-S2 / Q2a |
| BR-11 | 扫描为手动触发，无常驻监听 | 基线 Q2b |
| BR-12 | 用例无断言、无自动回归 | 基线 FR-C5 / Q10 |

## 9. 待确认问题

> 按优先级排列。**P0 会阻塞数据模型与流程设计**；P1 影响页面与交互设计；P2 可后置。

### 9.0 已确认结论（2026-11-19）

| 编号 | 问题 | 结论 | 对设计的影响 |
|---|---|---|---|
| DQ1 | 局部扫描的快照范围 | **A. 全项目快照，范围外标记"未比对"** | 扫描快照为项目级；扫描记录需保存本次范围与"未比对模块"；结果页与接口状态需能表达"本次未比对" |
| DQ2 | 人工修正的归属层 | **A. 存人工层，展示时覆盖源码层** | 人工层从"说明/示例"扩展到"参数/字段修正"；指纹只取源码层，人工修正不触发"已变更" |
| DQ3 | "已变更"退出条件 | **A. 用户确认变更后回到"已注册"** | 接口详情/变更提示需提供"确认变更"动作；状态机增加一条人工迁移 |
| DQ4 | 手工接口归属 | **C. 单列"手工接口"分组** | 接口树在 Maven 模块之外增加根级"手工接口"节点；手工接口不参与扫描对比；导出默认包含、可勾选排除（DQ18） |
| DQ5 | 用例可编辑范围 | **A. 可重命名/复制/改标签备注，快照不可改** | 用例实体拆为"可编辑元信息"与"不可变请求快照"；复制生成新用例 |
| DQ7 | 单接口文档 | **A. 纳入产品需求** | 文档导出增加"单接口"范围；与项目级共用同一 6 块模板 |
| DQ6 | 证书/代理层级 | **A. 环境级 + 全局默认值** | 环境实体增加证书校验、代理、免代理名单；全局提供默认值，环境覆盖全局 |
| DQ8 | 取消授权后结果 | **A. 取消即丢弃** | 扫描结果不持久化；待确认队列只存在于一次扫描会话内 |
| DQ9 | 左树与扫描范围 | **A. 全量 + 临时筛选** | 接口树始终为项目全量；增加"只看本次扫描"临时筛选，不改变接口清单定义 |
| DQ10 | 归档处理 | **A. 可恢复、不物理删除** | 归档为可逆状态；无物理删除；导出默认排除归档接口；恢复后回到已注册 |
| DQ11 | 项目操作 | **A. 支持重命名与删除** | 项目管理增加重命名/删除（删除需二次确认）；换目录后重新扫描，旧接口处理见 DQ19 |
| DQ18 | 手工接口导出 | **C. 导出时可勾选排除（默认包含）** | 导出设置增加"包含手工接口"开关，默认开启；不做单列、不额外标注来源 |
| DQ19 | 换目录后的旧接口 | **A. 保留并标记"目录已变更"** | 项目换源码目录不清理旧接口；旧接口打标，待下次扫描比对；不自动归档、不自动删除 |

> DQ1–DQ3 已不再阻塞数据模型与流程设计；DQ4–DQ11、DQ18、DQ19 已进入功能范围。
