# FeelPost 实现现状（2026-11-25）

> 本文档是当前代码的权威实现快照。`docs/design/01–07` 保留为设计过程记录；其中与本文冲突的内容以本文为准。

## 1. 产品与标识

- 用户可见产品名：**FeelPost**
- 技术标识：`feelpost`（package name、`window.feelpost`、环境变量、数据目录）
- 默认数据目录：`~/Documents/feelpost`
- 产品定位：本地接口契约中枢——扫描 Spring Boot 源码、调试接口、沉淀用例、导出 Markdown 给 AI 前端。

## 2. 技术架构

- Electron 33 + React 18 + TypeScript 5
- electron-vite + Vite 5
- 本地 JSON 文件存储，原子写
- zod IPC 入参校验；electron-log 日志
- web-tree-sitter（WASM）解析 Java
- undici 请求引擎
- 扫描在独立 `worker_threads` 中执行

## 4. AI 当前规则

- AI 默认关闭，可选；核心功能不依赖 AI。
- 设置页支持服务商预设：OpenAI、Anthropic Claude、Google Gemini、DeepSeek、通义千问、智谱 GLM、Kimi、MiniMax、OpenRouter、Ollama；选择后自动填 Base URL 与默认模型，按「国内 / 本地 / 国外」分组；可选择服务商后点击「获取模型」，从 `/models` 接口拉取可用模型列表；仅需填写 API Key。
- 设置状态依次为：未启用 / 未配置 / 缺少 Key / 待测试 / 连接异常 / 已启用。
- 测试连接失败自动重试一次；HTTP 2xx 即视为连接成功，不要求测试响应正文非空。
- 修改 Base URL、模型、API Key、超时或开关后，测试验证状态失效。
- 本地 Ollama 允许无 API Key；云端需要 Key。
- AI 用例文档 Prompt 版本：`case-doc.v4`。
- 每接口 H1 标题，字段按业务分组，请求头/入参/响应参数用表格，并包含请求/响应 JSON 示例。
- 多接口按接口分组；上下文超限时二分拆用例；仍超限时截断示例并提示。
- 缓存只用于用例文档；key 包含上下文 Hash、Base URL、模型、Prompt 版本。
- 缓存文件权限 `0600`，目录 `0700`，最多保留 50 个。
- 已下线：独立「AI 接入文档」、`aiDoc:*`、`AIDocumentService`、项目文档 AI 章节、`handoff` 特性。

## 5. 文档页

- 只保留「项目接口文档」。
- 支持按接口分页加载：首次 10 个，滚动续载。
- 筛选条件变化后重置分页并从第一页加载。
- 导出始终生成完整项目文档。
- 文档页左侧为白色卡片式导航；AI 接入文档入口已移除。

## 6. 交互与视觉约定

- 页面级错误统一使用底部 Message 提示，3 秒自动关闭，可点击关闭。
- 表单校验错误保留在对应字段附近。
- 设置页与文档/环境页一致：左侧白色固定侧栏，内容区滚动。
- 接口 Tab 支持右键：关闭当前、关闭所有、关闭左侧、关闭右侧。
- 目录操作悬浮显示「新建」「更多」；新建菜单包含目录/HTTP，更多菜单包含新建/移动至/编辑/删除。
- 新建 HTTP 自动创建空白 GET 接口并直接打开请求面板。

## 7. 打包

- `npm run pack`：macOS 生成 DMG，Windows 生成 NSIS 安装 exe。
- `npm run dist:mac`：macOS DMG+ZIP，arm64/x64。
- `npm run dist:win`：Windows NSIS+Portable，x64。
- 产物：`FeelPost-<version>-<arch>.dmg`、`FeelPost-<version>-<arch>.zip`、`FeelPost-<version>-x64-Setup.exe`、`FeelPost-<version>-x64-Portable.exe`。
- macOS 未签名/未公证；Windows 未做 Authenticode 签名。
- 扫描 Worker 与 chunks 通过 `asarUnpack` 解包，打包后扫描 smoke 通过。
