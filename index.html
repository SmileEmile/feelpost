本地部署

想从源码跑，命令都在这儿

不想用安装包，或者想自己构建客户端，直接照下面来。

本地部署
# Clone and start locally
git clone https://github.com/smileemile/feelpost.git
cd feelpost
npm install
npm run dev

# Build installers
npm run dist:mac:arm64   # macOS .dmg
npm run dist:win         # Windows .exe

安装包从 GitHub Releases 下载；这里是从源码运行与本地打包。
